Политика в отношении обработки персональных данных

Оператор: Халимуллин Руслан Ринатович · Тюмень
Действует в отношении информации, которую Оператор получает о Пользователе при использовании сайта https://kvartorio.github.io/kvartorio-quiz

1. Общие положения

Настоящая Политика обработки персональных данных (далее — Политика) действует в отношении всей информации, которую Халимуллин Руслан Ринатович (далее — Оператор) может получить о Пользователе во время использования им сайта https://kvartorio.github.io/kvartorio-quiz.

2. Состав персональных данных

Оператор может обрабатывать следующие персональные данные Пользователя:

  • фамилия, имя, отчество;
  • номер телефона;
  • предпочтения по подбору недвижимости (город, бюджет и иные параметры, указанные в форме).

3. Цели обработки персональных данных

Сбор данных осуществляется для следующих целей:

  • связь с Пользователем для оказания услуг по подбору недвижимости;
  • консультирование по вопросам купли-продажи объектов недвижимости;
  • направление подборок объектов, презентаций и аналитических материалов посредством мессенджеров и электронной почты.

4. Правовые основания и согласие

Обработка персональных данных осуществляется на основании согласия Пользователя, предоставляемого путем заполнения и отправки формы на сайте. Отправляя форму, Пользователь выражает свое согласие на условия настоящей Политики.

5. Порядок обработки и защита данных

Обработка персональных данных включает сбор, запись, систематизацию, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передачу (предоставление, доступ), обезличивание, блокирование, удаление, уничтожение персональных данных. Оператор принимает необходимые правовые, организационные и технические меры для защиты персональных данных от неправомерного доступа к ним.

6. Срок обработки и отзыв согласия

Обработка персональных данных осуществляется до достижения целей обработки (подбора недвижимости) или до отзыва согласия Пользователем. Пользователь может в любой момент отозвать свое согласие, направив Оператору уведомление на электронную почту kvartorio@ya.ru с пометкой «Отзыв согласия на обработку персональных данных».
